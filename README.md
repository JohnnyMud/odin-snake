# odin-snake

A terminal Snake game written in [Odin](https://odin-lang.org/).

## Requirements

- [Odin](https://odin-lang.org/docs/install/) installed and on your `PATH`
- A Unix-like terminal (macOS/Linux) — the game uses raw terminal input via POSIX

## Run

```bash
odin run .
```

## Controls

| Key | Action        |
|-----|---------------|
| `W` | Move up       |
| `A` | Move left     |
| `S` | Move down     |
| `D` | Move right    |
| `R` | Replay after game over |

Eat `*` to grow and score points. Hit a wall or yourself and it’s game over — press `R` to play again.
